# Electrical

How Team 2928 wires the robot so it's reliable, safe and easy to fix at competition.

## Start here

If you're new, read these in order:

1. [Electronics Basics](electronics-basics.md)
2. [FRC Control System](control-system.md)
3. [Crimping](crimping.md)
4. [Crimping CAN Connectors (Molex SL)](can-crimping.md)

!!! note "New controller in 2027"
    FRC is replacing the roboRIO with the Systemcore controller for the 2027 season. Our older robots still use a roboRIO. The [FRC Control System](control-system.md) page covers both.
