# Contributing

This guide will keep changing. If a rule is unclear or wrong, or something's missing, tell a design mentor or open a pull request.

## Adding a rule

Copy a file in `docs/cad/rules/` and keep the same four parts:

1. **The rule:** one or two sentences you can remember.
2. **What it means:** the rule in plain words.
3. **Why:** the reasoning, so people can judge edge cases.
4. **How:** the steps, with pictures or video.

Add it to `nav:` in `mkdocs.yml` and to the table in `cad/rules/index.md`. Group rules into sections when there are more than about eight, and run the draft past a mentor before it becomes a rule.
